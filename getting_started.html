Getting started#

About gridops#

gridops is an open-source production cost model (PCM) for three major U.S. interconnections (Western, Eastern, and ERCOT). It represents a reduced version of each interconnection’s network as nodes connected by transmission lines. It then uses a linear DC Optimal Power Flow (DC-OPF) approximation to optimize hourly unit commitment and economic dispatch over a rolling horizon. Each horizon dispatches generators and storage units to minimize the operating cost. The solve respects transmission limits, generator ramp rates, hydro energy budgets among many other constraints.

gridops is written in Python and builds its optimization models with Pyomo. Models can be solved with the open-source HiGHS solver (installed with gridops) or with the commercial Gurobi solver.

Installation#

Install the latest release from PyPI:

pip install gridops

To install the development version from GitHub instead:

git clone https://github.com/IMMM-SFA/gridops.git
cd gridops
pip install -e .

Optional extras are available for development:

pip install "gridops[test]"
pip install "gridops[docs]"

Check the installation:

import gridops as go

print(go.__version__)

Solvers#

HiGHS is open source and is installed automatically through the highspy dependency. Select it with solver_name="appsi_highs". No license is required.

Gurobi is a commercial solver and needs a valid license (free academic licenses are available). Install the Python bindings with:

pip install gurobipy

Select solver_name="appsi_gurobi" (persistent APPSI interface, which supports warm starts) or solver_name="gurobi".

See Solvers for solver options, warm starts and the automatic retry logic.

Example data#

gridops ships with a small example dataset for the U.S. Western Interconnection, installed with the package under gridops/data:

gridops/data/
├── example_config_file.yml      # configuration template pointing at the files below
├── example_inputs/              # 2 days of inputs on a 125-node, 786-line network
├── example_outputs/             # destination for the Parquet outputs
└── example_restart_files/       # destination for restart files and solver settings

You can find the folder on your machine with:

from importlib.resources import files

print(files("gridops").joinpath("data"))

The example network represents a 125-node, 786-line network. The inputs cover 48 hours, so the example can be run for up to two days.
