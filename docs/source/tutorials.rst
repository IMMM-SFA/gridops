Tutorials
=========

Jupyter notebooks that walk through complete gridops workflows. The pages show the
outputs saved in each notebook. You can download the notebooks from the
`notebooks folder <https://github.com/IMMM-SFA/gridops/tree/main/notebooks>`_ on
GitHub and run them locally.
