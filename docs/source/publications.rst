Publications
============

Peer-reviewed publications that describe or use ``gridops`` and its predecessor, the
``GO`` grid operations model, listed by year. If you have published work that uses ``gridops``, please
`open an issue <https://github.com/IMMM-SFA/gridops/issues>`_ so we can add it to this
list.
